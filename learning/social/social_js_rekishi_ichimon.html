人類の出現と文明のおこり①第1章

  • 約700万年前 アフリカに猿人（直立二足歩行・打製石器）→ 約260万年前〜 氷河時代に原人（火・言葉）→ 約20万年前 新人（私たちの直接の祖先）。
  • 打製石器で狩りや採集＝旧石器時代。約1万年前 農耕・牧畜が始まり、土器や磨製石器を使う新石器時代へ。
  • メソポタミア文明（チグリス川・ユーフラテス川）＝くさび形文字・太陰暦・青銅器・ハンムラビ法典・60進法。
  • エジプト文明（ナイル川）＝ピラミッド・象形文字・太陽暦（1年365日）。両方をふくむ地域がオリエント（紀元前1000年ごろから鉄器）。
  • インダス文明（紀元前2600年ごろ）＝モヘンジョ＝ダロ（道路・排水溝）、インダス文字。

人類の出現と文明のおこり②第2章

  • 中国：殷（紀元前1600年ごろ・青銅器・甲骨文字）→ 春秋・戦国時代に孔子が儒教 → 秦の始皇帝が統一・万里の長城 → 漢の大帝国・シルクロード（絹の道）。
  • 朝鮮半島：北部に高句麗、南部の西に百済・東に新羅、南端に加羅（伽耶）。
  • ギリシャ：都市国家（ポリス）で成年男子による民主政 → アレクサンドロス大王の東方遠征でヘレニズム文化 → ローマ帝国（紀元前30年ごろ帝政）。
  • 宗教：仏教（シャカ・インド）／ヒンドゥー教（バラモンの教え）／キリスト教（イエス・パレスチナ）／イスラム教（ムハンマド・7世紀・聖典「コーラン」）。

日本の成り立ちと倭の王権第3章

  • 旧石器時代＝打製石器（岩宿遺跡）。縄文時代＝縄文土器・磨製石器・貝塚・竪穴住居・土偶（三内丸山遺跡）。
  • 弥生時代＝稲作（石包丁・高床倉庫）・弥生土器・青銅器（銅鐸は祭りの道具）。ムラからクニへ。
  • 中国は日本を倭とよんだ。1世紀 奴国の王が金印（「漢委奴国王」）／3世紀 邪馬台国の卑弥呼が魏に使い（「魏志」倭人伝）。
  • 古墳時代＝前方後円墳・埴輪。大王を中心に大和政権（ヤマト王権）。日本最大は大仙古墳（大阪府堺市）。
  • 渡来人が須恵器・絹織物などの技術、漢字・儒教・仏教を伝える。

大帝国の出現と律令国家の形成第4章

  • 中国：6世紀末 隋が統一（律令）→ 7世紀前半 唐（都長安は国際都市）。朝鮮は新羅が統一。イスラム世界の首都はバグダッド。
  • 聖徳太子（厩戸皇子）が推古天皇の摂政に。蘇我馬子と協力し冠位十二階・十七条の憲法・遣隋使（小野妹子）。
  • 飛鳥文化（日本最初の仏教文化）＝法隆寺（現存する世界最古の木造建築）。
  • 645年 大化の改新（中大兄皇子・中臣鎌足）＝公地・公民。663年 白村江の戦いに敗れる → 天智天皇 → 壬申の乱 → 天武天皇。
  • 701年 大宝律令で律令国家に。地方の国に都から国司、郡には地方の豪族を郡司に。

貴族社会の発展①第5章

  • 710年 平城京（奈良時代）。貨幣は和同開珎。九州に大宰府、東北に多賀城。
  • 戸籍に基づき6歳以上に口分田＝班田収授法。税の荷札は木簡。
  • 税：租（稲の約3％）／調（特産物）／庸（麻の布）／雑徭（労役）／兵役（九州北部の守り＝防人）。
  • 743年 墾田永年私財法で開墾地の永久私有を認める。
  • 遣唐使・鑑真の来日。聖武天皇の天平文化＝国分寺・東大寺（大仏・行基）・正倉院。「古事記」「日本書紀」「風土記」「万葉集」。

貴族社会の発展②第6章

  • 794年 桓武天皇が平安京へ（平安時代）。坂上田村麻呂を征夷大将軍に任命して蝦夷を従わせる。
  • 藤原氏の摂関政治（幼い天皇には摂政、成人した天皇には関白）。藤原道長・頼通のとき全盛。貴族や寺社の私有地＝荘園。
  • 新しい仏教：最澄＝天台宗（比叡山延暦寺）／空海＝真言宗（高野山金剛峯寺）。
  • 894年 菅原道真の進言で遣唐使停止 → 国風文化＝寝殿造・仮名文字・「古今和歌集」（紀貫之）・「源氏物語」（紫式部）・「枕草子」（清少納言）。
  • 浄土の教え（念仏で極楽浄土へ）→ 平等院鳳凰堂（藤原頼通・宇治）。中国では宋が統一。

武家政治の始まり①第7章

  • 棟梁を頂点とする武士団。10世紀 関東の平将門・瀬戸内の藤原純友の反乱。関東に源氏、西日本に平氏。平泉の奥州藤原氏＝中尊寺金色堂。
  • 土地は国司が支配する公領と、貴族や寺社に寄進された荘園。
  • 1086年 白河天皇が上皇となって院政。
  • 1156年 保元の乱（後白河天皇の勝利）→ 1159年 平治の乱（平清盛が源義朝を破る）。
  • 平清盛が武士で初めて太政大臣。大輪田泊を整備して宋と貿易、厳島神社。→ 源頼朝が伊豆で挙兵、源義経が1185年 壇ノ浦で平氏をほろぼす。

武家政治の始まり②第8章

  • 鎌倉幕府：国ごとに守護、荘園・公領ごとに地頭（1185年）。1192年 頼朝が征夷大将軍。
  • 将軍と御家人は御恩と奉公＝土地を仲立ちにした封建制度。
  • 北条氏の執権政治。1221年 後鳥羽上皇の承久の乱 → 京都に六波羅探題。1232年 北条泰時が御成敗式目（貞永式目）。
  • 米と麦の二毛作、定期市（宋銭）。
  • 鎌倉文化：軍記物「平家物語」（琵琶法師）・東大寺南大門の金剛力士像（運慶・快慶）。
  • 新しい仏教：浄土宗（法然）・浄土真宗（親鸞）・時宗（一遍）・日蓮宗（日蓮）・禅宗（栄西＝臨済宗、道元＝曹洞宗）。

ユーラシアの動きと武家政治の変化①第9章

  • チンギス＝ハンがモンゴル帝国。フビライ＝ハンが国号を元に、高麗を従える。
  • 執権北条時宗が要求を拒否 → 元寇＝1274年 文永の役・1281年 弘安の役（博多湾に石塁（防塁））。
  • 御家人の困窮 → 1297年 徳政令。悪党の出現、北条氏が権力を独占。
  • 1333年 後醍醐天皇が足利尊氏・新田義貞・楠木正成らと鎌倉幕府をほろぼす → 建武の新政（2年余りで失敗）。
  • 後醍醐天皇は吉野に南朝、足利尊氏は京都に北朝＝南北朝時代（約60年）。守護は守護大名に成長。
  • 3代将軍足利義満が南北朝を統一（1392年）、京都の室町に御所＝室町幕府。将軍の補佐役は管領。

ユーラシアの動きと武家政治の変化②第10章

  • 倭寇が中国・朝鮮の沿岸を襲う。中国に明（陽明学・万里の長城）。
  • 足利義満は明から「日本国王」と認められ、勘合貿易（日明貿易）。輸入品＝明銭（銅銭）・生糸・絹織物、輸出品＝銅・硫黄・刀剣。
  • 李成桂が高麗を倒して朝鮮（ハングル・朱子学）。対馬の宗氏が貿易を独占し、木綿を輸入。
  • 沖縄：按司のグスク → 15世紀初め 尚巴志が琉球王国（首里城・港は那覇）＝中継貿易。
  • 蝦夷地（北海道）のアイヌ民族。1457年 コシャマインの戦い。

結びつく民衆と下剋上の社会第11章

  • 二毛作・かんがい、商品作物。運送は馬借・問（問丸）、金貸しは土倉・酒屋、同業者組合の座。堺・京都では町衆が自治。
  • 村の自治組織惣、寄合でおきて。1428年 正長の土一揆（一揆）。
  • 1467年 応仁の乱→ 下剋上の風潮・山城の国一揆・加賀の一向一揆 → 戦国時代（分国法・城下町）。
  • 北山文化：金閣（足利義満）・能（観阿弥・世阿弥）・狂言・連歌。
  • 東山文化：銀閣（足利義政）・書院造・枯山水・雪舟の水墨画・御伽草子。

結びつく世界との出会い第12章

  • ローマ教皇を首長とするカトリック教会。イスラム法は「コーラン」に基づく。聖地エルサレムをめぐり十字軍。
  • 14世紀イタリアでルネサンス＝レオナルド＝ダ＝ビンチ「モナ＝リザ」・ミケランジェロ「ダビデ」。
  • 16世紀 ルター（ドイツ）・カルバン（スイス）の宗教改革→ プロテスタント。オスマン帝国（トルコ）・ムガル帝国（北インド）。
  • 新航路：コロンブス（スペインの援助）・バスコ＝ダ＝ガマ（ポルトガル）・マゼラン。植民地・イエズス会。17世紀 オランダが東インド会社。
  • 1543年 種子島に鉄砲（産地は堺・国友）。1549年 フランシスコ＝ザビエルがキリスト教を伝える。南蛮貿易。

天下統一への歩み第13章

  • 織田信長：桶狭間の戦い（今川義元）→ 1573年 室町幕府をほろぼす → 長篠の戦い（鉄砲で武田氏）、延暦寺焼き討ち。
  • 安土城の城下で楽市・楽座、関所の廃止。1582年 本能寺の変（明智光秀）。
  • 豊臣秀吉：大阪城・1585年 関白・1590年 全国統一。太閤検地・刀狩→ 兵農分離。
  • 二度の朝鮮出兵（文禄・慶長の役）。連れてこられた陶工が有田焼。
  • 桃山文化：姫路城・天守・狩野永徳・千利休の侘び茶。南蛮文化。民衆の衣料は木綿、出雲の阿国のかぶき踊り。

幕藩体制の確立と「鎖国」①第14章

  • 1600年 関ヶ原の戦い（石田三成を破る）→ 1603年 徳川家康が江戸幕府。五街道を整備。
  • 幕藩体制（大名の領地＝藩）。将軍を助けるのは老中。大名は親藩・譜代大名・外様大名。
  • 武家諸法度（1615年〜）。3代徳川家光が参勤交代を制度化。
  • 朱印状→ 朱印船貿易→ 東南アジアに日本町（山田長政）。
  • 1637年 島原・天草一揆。絵踏・宗門改。1641年 オランダ商館を出島へ＝のちの「鎖国」（相手は中国とオランダ）。

幕藩体制の確立と「鎖国」②第15章

  • 4つの窓口：長崎（オランダ＝出島・中国＝唐人屋敷）・対馬藩（朝鮮）・薩摩藩（琉球）・松前藩（アイヌ民族）。
  • 中国は清（女真族）に。オランダ風説書で海外の情報。朝鮮からは朝鮮通信使。
  • 1609年 薩摩藩が琉球王国を征服。1669年 シャクシャインが松前藩と戦う。
  • 身分：武士（名字・帯刀）／百姓（人口の約84％）／町人。百姓は本百姓（土地あり）と水呑百姓（土地なし）。
  • 年貢は収穫の40〜50％。村役人＝名主（庄屋）・組頭・百姓代。共同責任の五人組。

経済の成長と幕政の改革①第16章

  • 新田開発、備中ぐわ・千歯こき、干鰯・油かす。西廻り航路・東廻り航路。
  • 江戸＝「将軍のおひざもと」、大阪＝「天下の台所」（蔵屋敷）。株仲間・両替商。
  • 5代徳川綱吉（湯島聖堂・儒学）→ 新井白石（貨幣の質をもどす・長崎貿易の制限）。
  • 元禄文化（上方の町人）：井原西鶴の浮世草子・近松門左衛門の人形浄瑠璃・松尾芭蕉「おくのほそ道」・菱川師宣「見返り美人図」。
  • 8代徳川吉宗の享保の改革：上げ米の制・目安箱・公事方御定書。
  • 商品作物・問屋制家内工業・地主と小作人。百姓一揆（からかさ連判状）・打ちこわし。

経済の成長と幕政の改革②第17章

  • 老中田沼意次（株仲間・俵物の輸出）→ 老中松平定信の寛政の改革（昌平坂学問所で朱子学）。
  • 1792年 ロシアのラクスマン来航。1825年 異国船打払令→ 蛮社の獄（渡辺崋山・高野長英）。
  • 工場制手工業（マニュファクチュア）。1837年 大塩平八郎の乱、岡山藩の渋染一揆。
  • 老中水野忠邦の天保の改革（株仲間の解散・失敗）。藩政改革＝肥前藩（佐賀藩）の反射炉、薩摩・長州。
  • 国学（本居宣長）／蘭学（杉田玄白ら「解体新書」）／伊能忠敬の日本地図。
  • 化政文化（江戸の町人）：錦絵（喜多川歌麿・葛飾北斎・歌川広重）・十返舎一九・滝沢馬琴・小林一茶。庶民は寺子屋、武士は藩校。

近代世界の確立とアジア①第18章

  • イギリス：イギリス国教会。エリザベス1世がスペインの無敵艦隊を破る＝絶対王政。
  • 1649年 ピューリタン革命（クロムウェル）→ 1688年 名誉革命・権利の章典→ 立憲君主制と議会政治。
  • フランス：ルイ14世の絶対王政・ベルサイユ宮殿。
  • 啓蒙思想：ロック（抵抗権・社会契約説）・モンテスキュー（「法の精神」三権分立）・ルソー（「社会契約論」人民主権）。
  • 13植民地がイギリスから独立＝1776年 独立宣言→ アメリカ合衆国（ワシントン）・合衆国憲法。
  • 1789年 フランス革命：平民の代表が国民議会、バスティーユ牢獄の襲撃、人権宣言→ ナポレオンが皇帝に。

近代世界の確立とアジア②第19章

  • 18世紀後半 イギリスで産業革命（石炭を燃料とする蒸気機関）＝「世界の工場」。資本主義とその問題→ マルクスらの社会主義。
  • アメリカ：南部は綿花のプランテーション → 1861年 南北戦争（リンカンの奴隷解放宣言）。
  • ロシア：クリミア戦争に敗れ農奴解放令。イタリア統一（1870年）、ビスマルクのドイツ帝国（1871年）＝近代化と列強。
  • インド：ムガル帝国。イギリスの安い綿織物で手工業がおとろえる → 1857年 インド大反乱→ イギリスが直接支配。
  • 中国：イギリスは清から茶を輸入、インドのアヘンを密輸（三角貿易）→ 1840年 アヘン戦争→ 南京条約（香港をゆずる）→ 洪秀全の太平天国。

開国と幕府政治の終わり第20章

  • 1853年 ペリーが浦賀に来航 → 1854年 日米和親条約（下田・函館）。
  • 1858年 日米修好通商条約（井伊直弼・5港）＝領事裁判権を認め、関税自主権がない不平等条約。
  • 最大の貿易相手はイギリス。輸出の中心は生糸、安い綿織物の輸入で国内の生産地が打撃。
  • 安政の大獄→ 1860年 桜田門外の変（井伊直弼暗殺）。尊王攘夷運動（中心は長州藩）。
  • 薩英戦争・四国連合艦隊の下関砲台占領 → 攘夷から倒幕へ。薩摩＝西郷隆盛・大久保利通、長州＝木戸孝允・高杉晋作。坂本龍馬の仲立ちで薩長同盟（1866年）。
  • 「世直し」一揆・「ええじゃないか」→ 1867年 大政奉還（徳川慶喜）→ 王政復古の大号令→ 1868年〜 戊辰戦争。

明治維新と立憲国家への歩み①第21章

  • 1868年 五箇条の御誓文、一世一元の制、江戸を東京に＝一連の改革が明治維新。太政官のもとで藩閥政治。
  • 1869年 版籍奉還→ 1871年 廃藩置県（県令を派遣）。
  • 四民平等：公家・大名＝華族、武士＝士族、百姓・町人＝平民。1871年 解放令。
  • 富国強兵：1872年 学制／1873年 徴兵令（満20歳の男子）／1873年 地租改正（地価の3％を現金で→1877年に2.5％）。
  • 殖産興業：富岡製糸場（群馬県）・1872年 新橋〜横浜に鉄道・郵便制度。
  • 文明開化：福沢諭吉「学問のすゝめ」・中江兆民、れんが造り・ガス灯・太陽暦。

明治維新と立憲国家への歩み②第22章

  • 1871年 岩倉使節団（条約改正は失敗）。日清修好条規（対等）。征韓論→ 1876年 日朝修好条規（江華島事件）。
  • 1875年 樺太・千島交換条約。北海道に開拓使・屯田兵。1872〜79年 琉球処分で沖縄県。
  • 1874年 板垣退助らの民撰議院設立建白書 → 自由民権運動。1877年 西郷隆盛の西南戦争。
  • 国会開設の約束 → 自由党（板垣退助・1881年）・立憲改進党（大隈重信・1882年）。
  • 1885年 内閣制度（初代総理大臣伊藤博文）。ドイツ（プロイセン）の憲法を参考に1889年 大日本帝国憲法（主権は天皇）。
  • 1890年 第1回帝国議会（貴族院・衆議院）・教育勅語。「家」を重んじる民法。

激動する東アジアと日清・日露戦争①第23章

  • 1869年 スエズ運河開通。列強の帝国主義：イギリス（インド・ビルマ）・フランス（インドシナ）・ロシア（シベリア鉄道）・アメリカ（ハワイ・フィリピン）。
  • 条約改正：鹿鳴館の欧化政策→ 1886年 ノルマントン号事件→ 1894年 陸奥宗光が領事裁判権を撤廃 → 1911年 小村寿太郎が関税自主権を回復。
  • 1894年 甲午農民戦争→ 日清戦争→ 1895年 下関条約（朝鮮の独立、遼東半島・台湾・澎湖諸島、賠償金約2億両）。
  • ロシア・ドイツ・フランスの三国干渉で遼東半島を返還。1900年 伊藤博文が立憲政友会を結成。
  • 1897年 朝鮮が大韓帝国に。1900年 義和団事件。1902年 日英同盟。

激動する東アジアと日清・日露戦争②第24章

  • 韓国・満州をめぐりロシアと対立。非戦論＝内村鑑三（キリスト教）・幸徳秋水（社会主義）・与謝野晶子「君死にたまふことなかれ」。
  • 1904年 日露戦争（旅順・奉天、東郷平八郎の日本海海戦）→ アメリカの仲立ちで1905年 ポーツマス条約（樺太の南半分など。賠償金なし）→ 日比谷焼き打ち事件。
  • 韓国に統監府→ 義兵の抵抗 → 1910年 韓国併合・朝鮮総督府・同化政策。
  • 満州に南満州鉄道株式会社（満鉄）→ アメリカとの対立。
  • 孫文の三民主義→ 1911年 辛亥革命→ 1912年 中華民国（南京）→ 袁世凱が首都を北京へ。

近代の産業と文化の発展第25章

  • 軽工業の産業革命：製糸業（生糸→アメリカ）・紡績業（綿糸）。資本主義の確立、財閥。
  • 重工業：1901年 八幡製鉄所（日清戦争の賠償金・福岡県）、日露戦争後に造船業。鉄道の国有化。
  • 農村は地主と小作人。工場の女工、労働争議。1910年 大逆事件。足尾銅山鉱毒事件＝田中正造。
  • 1886年 学校令で義務教育4年（のち6年）。津田梅子の女子英学塾。野口英世（黄熱病）・北里柴三郎・志賀潔。
  • 文学：言文一致（二葉亭四迷）・樋口一葉・夏目漱石・森鷗外。美術：横山大観・黒田清輝。音楽：滝廉太郎「荒城の月」。
