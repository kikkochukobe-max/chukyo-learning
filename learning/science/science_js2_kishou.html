📋 地球の大気と天気の変化 まとめ表

圧力

  • 圧力＝一定面積（1m²など）あたりの面を垂直に押す力の大きさ
  • 単位はパスカル（記号 Pa）。1Pa＝1N/m²（ニュートン毎平方メートル）
  • 1m²＝10000cm²。cm²で出した面積は10000でわってm²にする
  • 100gの物体にはたらく重力の大きさを1Nとする（1kg→10N）
圧力〔Pa〕＝面を垂直に押す力の大きさ〔N〕力がはたらく面積〔m²〕
  • 力の大きさが同じなら、面積が小さいほど圧力は大きい（スポンジが深くへこむ）
  • 板の面積が半分になると、へこみぐあい（圧力）は2倍
  • 同じ物体を2個重ねると、面積は同じで力が2倍→圧力も2倍
  • 置く向きを変えても力は同じ。下にする面がいちばん小さいとき圧力が最大

大気圧（気圧）

  • 大気圧（気圧）＝大気（地球を包む気体の層）の重さによって生じる圧力
  • 単位はヘクトパスカル（記号 hPa）。1hPa＝100Pa
  • 海面と同じ高さで平均約1013hPa＝1気圧（約101300N/m²）
  • 大気圧はあらゆる向きから物体の面に垂直にはたらく
  • 上空へ行くほど、その上にある大気の重さが小さくなるので、大気圧は小さくなる （富士山頂は約640hPa）
  • 密封した菓子袋を標高の高いところに持っていくとふくらむ（外の気圧が小さくなるため）
  • 空き缶の中の空気をぬく・熱して冷やすとつぶれる（外の大気圧に押される）

気象要素と雲量

  • 気象要素＝大気の状態を表す要素（気温・湿度・気圧・風向・風速・雲量・降水量など）
  • 雲量＝空全体を10としたときの、雲が空をしめる割合
雲量0〜12〜89〜10
天気（雨・雪がないとき）快晴晴れくもり

天気記号

風向・風速・風力

  • 風向＝風がふいてくる方位。16方位で表す。風向計・ふき流しで調べる
  • ふき流しが南東になびいている → 風は北西からふいている → 風向は北西
  • 風速（単位 m/s）は風速計で調べる。風速計がないときは風力階級表で風力（0〜12の13段階）を決める
  • 天気図記号：矢の軸を風がふいてくる方位に向けてかき、風力をはねの数で表す

気温・湿度のはかり方

  • 地上から約1.5mの高さで、風通しのよい日かげに置いた乾湿計で測定する（直射日光はさける）
  • 気温＝乾球温度計の示度
  • 湿度＝乾球と湿球の示度の差から湿度表で求める（湿球は水でぬらした布で包んである）
  • 湿球は水が蒸発するとき熱をうばうので、ふつう乾球より低い示度になる。差が0なら湿度100%
  • 差が大きいほど湿度は低い（空気が乾燥しているほど水がよく蒸発する）
  • 気圧はアネロイド気圧計などで測定する
湿度表の読み方：たて＝乾球の示度、よこ＝乾球と湿球の示度の差 → 交わったところが湿度〔%〕

天気と気温・湿度・気圧

晴れの日くもり・雨の日
気温1日の変化が大きい。昼すぎ（14時ごろ）に最高、明け方に最低1日の変化が小さい
湿度気温と逆の変化をする（気温が上がると湿度は下がる）1日の変化が小さく、高いまま
気圧高い（大きい）ことが多い低い（小さい）ことが多い

霧・雲のでき方

  • 霧＝水蒸気を多くふくんだ空気が地表付近で冷やされ、水蒸気が小さな水滴になって地表付近にただよっているもの。気温が上がると水滴が水蒸気になって消える
  • 雲＝上昇する空気の中にできた小さな水滴や氷の粒の集まり
  • 上昇気流＝上昇する空気の動き／下降気流＝下降する空気の動き（雲ができにくい）
  • 上昇気流ができる例：① 太陽の熱で地表付近の空気があたためられる ② 空気が山の斜面に沿って上昇する ③ あたたかい空気が冷たい空気の上にはい上がる（冷たい空気があたたかい空気をおし上げる）
空気が上昇 → 上空ほど気圧が低いので膨張 → 温度が下がる → 露点に達する → 水蒸気が水滴（0℃以下で氷の粒）になる → 雲
  • 雲ができはじめる高さ＝空気の温度が露点に達する高さ。上昇する空気は100mにつき約1℃温度が下がる
  • 雲の中の水滴や氷の粒がぶつかって大きくなり落ちてくる＝降水。とけずに落ちれば雪、とけて落ちれば雨
  • 水の循環：太陽光（太陽のエネルギー）をエネルギー源として、水は気体・液体・固体とすがたを変えながら地表と大気の間を循環している

雲をつくる実験（フラスコと注射器）

  • フラスコの内側をぬるま湯でぬらし、線香のけむりを入れる（けむりは水滴ができるときの芯になる）
  • ピストンを引く → 空気が膨張 → 温度が下がる → 白くくもる
  • ピストンを押す → 空気が圧縮 → 温度が上がる → くもりが消える

飽和水蒸気量・露点・湿度

  • 飽和水蒸気量＝空気1m³中にふくむことのできる水蒸気の最大量（単位 g/m³）。気温が高いほど大きい
  • 露点＝冷やされた空気中の水蒸気が水滴に変わりはじめるときの温度。このとき湿度は100%
  • 露点は空気中の水蒸気量で決まる（水蒸気量が多いほど露点は高い）
  • 露点より低い温度まで冷やすと、飽和水蒸気量をこえた分が水滴になる
  • 金属製のコップを使うのは熱を伝えやすく、コップの表面の空気の温度が水温とほぼ同じになるから
湿度〔%〕＝空気1m³中にふくまれる水蒸気量〔g/m³〕その温度での飽和水蒸気量〔g/m³〕×100
  • 水蒸気量が変わらなければ、温度が低いほど湿度は高い
  • 同じ温度なら、水蒸気量が多いほど湿度は高い

高気圧・低気圧と風

  • 等圧線＝気圧が等しい地点を結んだ曲線。1000hPaを基準に4hPaごとに細線、20hPaごとに太線
  • 高気圧＝等圧線が閉じ、まわりより気圧が高いところ／低気圧＝まわりより気圧が低いところ
  • 天気図＝気圧配置（気圧の分布のようす）を示した地図に、天気図記号で天気や風のようすを表したもの
  • 風は気圧の高いほうから低いほうへふく。等圧線の間隔がせまいほど風が強い
北半球高気圧低気圧
地表の風中心から時計回りにふき出す中心へ反時計回りにふきこむ
中心付近の気流下降気流上昇気流
天気雲ができにくく晴れが多い雲ができやすくくもりや雨が多い

気団と前線

  • 気団＝気温や湿度などの性質がほぼ一様な、大規模な大気のかたまり
  • 前線面＝寒気と暖気が接する境界面／前線＝前線面が地面と交わってできる線
  • 寒気は暖気より密度が大きい（重い）ので下にもぐりこむ
前線でき方・進み方記号
寒冷前線寒気が暖気の下にもぐりこみ、暖気を急激に押し上げるように進む
温暖前線暖気が寒気の上にはい上がり、寒気を押しながら進む
停滞前線ほぼ同じ勢力の寒気と暖気がぶつかり、ほとんど動かない（梅雨前線・秋雨前線）
閉塞前線寒冷前線が温暖前線に追いついてできる

温帯低気圧と前線の通過

  • 温帯低気圧＝中緯度で発生する低気圧。日本付近では中心の東側に温暖前線、西側に寒冷前線をともなうことが多い
  • 2つの前線にはさまれた南側は暖気におおわれている
  • 低気圧は偏西風の影響で西から東へ移動する
寒冷前線温暖前線
できる雲積乱雲（強い上昇気流）乱層雲など（巻雲・巻層雲・高層雲も）
雨せまい範囲に強いにわか雨が短時間。雷・突風をともなうことも広い範囲におだやかな雨が長時間
通過後の気温急に下がる上がる
通過後の風向北より（北西など）に変わる南より（南西など）に変わる

天気の移り変わり

  • 日本付近の低気圧や移動性高気圧は、1日におよそ1000kmの速さで西から東へ移動する → 天気も西から東へ変わる
  • 気圧が下がると天気はくもりや雨に、気圧が上がると晴れになることが多い

地球規模での大気の動き

  • 大気の動きは、地球の半径約6400kmに対して大気の層の底の約10kmの中で起こる
  • 偏西風＝中緯度帯の上空を1年中ふいている西よりの風。日本付近の低気圧・移動性高気圧が西から東へ移動するのはこのため
  • 低緯度の地表付近では東よりの風、高緯度の地表付近でも東よりの風がふく
  • 赤道付近では上昇気流、北極付近では下降気流

海風・陸風と季節風

  • 陸は海よりあたたまりやすく冷えやすい（海はあたたまりにくく冷えにくい）
  • 晴れた日の昼：陸上の気温が高い → 陸上に上昇気流 → 陸上の気圧が低くなる → 海から陸へ海風
  • 晴れた日の夜：陸上の気温が低い → 陸上に下降気流 → 陸上の気圧が高くなる → 陸から海へ陸風
  • 朝夕、風が止まることをなぎという
  • 季節風＝大陸と海洋のあたたまり方のちがいで、季節に特徴的にふく風。冬は北西、夏は南東
  • 夏の季節風は海風、冬の季節風は陸風と同じしくみ

日本周辺の気団

気団性質季節
シベリア気団冷たく乾燥（北・大陸）冬
オホーツク海気団冷たく湿っている（北・海洋）梅雨・夏の前
小笠原気団あたたかく湿っている（南・海洋）夏
  • 北の気団は南の気団より低温／大陸の気団は海洋の気団より乾燥

日本の四季の天気

季節気圧配置・特徴
冬シベリア気団が発達 → 西高東低。北西の季節風。日本海側は雪、太平洋側は乾燥した晴れ。等圧線が南北にせまい間隔で並ぶ・すじ状の雲
春・秋移動性高気圧と低気圧が交互に西から東へ通過 → 4〜7日の周期で天気が変わる
つゆ（梅雨）初夏、小笠原気団とオホーツク海気団の間に停滞前線（梅雨前線） → 雨やくもりの日が続く。夏の終わりは秋雨前線
夏小笠原気団がはり出し南高北低。南東の季節風で蒸し暑い。強い日ざしで積乱雲が発達し雷雨も
  • 冬の日本海側の雪：冷たく乾燥した季節風が、比較的あたたかい日本海の上で水蒸気を多量にふくみ、山脈にあたって上昇気流となり雲をつくる。山をこえた太平洋側は乾燥した風になる
  • 台風＝熱帯の海上で発生した熱帯低気圧が発達し、最大風速が17.2m/s以上になったもの。前線をともなわない。等圧線は同心円状で間隔がせまい
  • 台風は太平洋高気圧のふちに沿って北上し、やがて偏西風に流されて北東へ進む

天気の変化がもたらす恵みと災害

  • 恵み：豊富な水資源（つゆや台風の雨）→ 農業・工業用水・生活用水・発電。雪はスキーなどのレジャーや夏の冷房・冷蔵に利用
  • 災害：大雪・高潮・洪水・土砂災害・低温（霜）による農作物の被害など
  • 高潮＝台風などで気圧が下がって海面が吸い上げられたり、強い風で海水がふき寄せられたりして、海面が異常に上昇する現象
  • 備え：ダム・堤防・遊水地（河川沿いの低地に一時的に水をたくわえる）。地域の地理的な特徴をふまえ、気象情報を活用する

圧力

圧力〔Pa〕＝力〔N〕面積〔m²〕　　力〔N〕＝質量〔g〕÷100　　面積〔m²〕＝面積〔cm²〕÷10000
  • （例）重さ10Nで底面積2m² → 10÷2＝5Pa
  • （例）質量2.4kg（24N）の物体を8cm×15cm（0.012m²）の面で置く → 24÷0.012＝2000Pa
  • （例）大気圧1000hPa（100000Pa）が1cm²（0.0001m²）を押す力 → 100000×0.0001＝10N（1kgの物体の重さと同じ）

湿度

湿度〔%〕＝空気1m³中の水蒸気量その温度での飽和水蒸気量×100
  • （例）20℃（飽和水蒸気量17.3g/m³）で1m³中に12.1g → 12.1÷17.3×100＝69.9…→ 約70%
  • 水蒸気量＝飽和水蒸気量×湿度÷100（例：20℃・湿度60% → 17.3×0.6＝10.4g）
  • 部屋全体の水蒸気量＝1m³あたりの水蒸気量×部屋の容積〔m³〕

露点と水滴

  • 露点＝空気中の水蒸気量と飽和水蒸気量が等しくなる温度（表で同じ値をさがす）
  • あと何g水蒸気をふくめるか＝飽和水蒸気量－実際の水蒸気量
  • 出てくる水滴の量＝実際の水蒸気量－冷やした温度での飽和水蒸気量
  • （例）1m³中12.1gの空気（露点14℃）を10℃（9.4g/m³）まで冷やす → 12.1－9.4＝2.7gの水滴

雲ができる高さ

雲ができはじめる高さ〔m〕＝（地上の気温－露点）×100　（雲ができるまでは100mにつき約1℃下がる）
  • （例）地上20℃・露点8℃の空気 → (20－8)×100＝1200m
  • フェーン現象：雲ができてからは100mにつき約0.5℃しか下がらず、山をふき下りる空気は100mにつき1℃上がる → 風下側は高温で乾燥

天気図

  • 等圧線は4hPaごと（20hPaごとに太線）。太線1000hPaから数えて気圧を読む
