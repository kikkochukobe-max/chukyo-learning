📋 身のまわりの現象 まとめ表

光の進み方

  • 光源＝自ら光を出す物体（太陽・電灯・燃えているろうそく）
  • 光の直進＝光がまっすぐ進む現象。光源から出た光は四方八方に広がりながら直進する
  • 光源でない物体が見えるのは、物体に当たってはね返った光が目に入るから
  • 光の速さは約30万km/s（音よりはるかに速い）

光の反射

  • 入射光＝物体に当たる光／反射光＝はね返った光
  • 入射角・反射角は面に垂直な直線（法線）との角。鏡の面との角ではない
  • 反射の法則＝入射角＝反射角
  • 乱反射＝でこぼこした面で光がさまざまな方向に反射すること。どの向きからでも物体が見えるのは乱反射のおかげ。1つ1つの光は反射の法則にしたがう
鏡の面と光のなす角が a° のとき　入射角＝90°−a°

鏡にうつる像

  • 像＝鏡などにうつって見えるもの。鏡の像は虚像
  • 像は鏡の面に対して物体と対称の位置にできる
  • 大きさは物体と同じ／左右の向きは反対
  • 2枚の鏡を90°に組み合わせると像は3つ（像1・像2は左右逆、像3は左右同じ向き）
全身がうつる鏡の縦の長さ＝身長×12　／　鏡の下端の高さ＝目の高さ×12

光の屈折

  • 屈折＝種類のちがう物質へ進むとき、境界面で折れ曲がって進む現象。屈折と同時に一部は反射する
  • 境界面に垂直に入射したとき → 屈折せず直進する
  • 水中のコインが浮き上がって見える・ストローが折れて見えるのは屈折のため
  • 半円形ガラスの中心へ入射させると、曲面側では屈折せず直進する
光の進む向き屈折角と入射角覚え方
空気 → 水・ガラス屈折角 < 入射角境界面に垂直な線に近づく
水・ガラス → 空気屈折角 > 入射角境界面に垂直な線から遠ざかる
垂直に入射屈折しないそのまま直進

全反射と光の色

  • 全反射＝水・ガラスから空気へ進むとき、入射角がある大きさより大きくなると屈折せずすべて反射する現象
  • ★空気から水へ進むときは全反射は起こらない
  • 利用＝光ファイバー（光通信・内視鏡）
  • 太陽光（白色光）をプリズムに通すと、色によって屈折角がちがうため色に分かれる。にじは空気中の水滴がプリズムのようにはたらいてできる
  • 可視光線＝目に見える光。目に見えない光には赤外線・紫外線がある

凸レンズの性質

  • 凸レンズ＝ふちより中央がふくらんだレンズ。光を屈折させて集める（入るとき・出るときの2回屈折）
  • 焦点＝光軸に平行な光が屈折して集まる点。レンズの両側に1つずつ、合計2つ
  • 焦点距離＝レンズの中心から焦点までの距離
  • ふくらみが大きいほど焦点距離は短い

凸レンズを通る3本の光

  • ① 光軸に平行な光 → 屈折して焦点を通る
  • ② 焦点を通る光 → 屈折して光軸に平行に進む
  • ③ レンズの中心を通る光 → そのまま直進
  • 作図ではレンズの中心線で1回屈折するようにかく

実像と虚像

実像虚像
物体の位置焦点の外側焦点の内側
向き上下・左右が逆（倒立）実物と同じ（正立）
大きさ位置で変わる実物より大きい
スクリーンうつるうつらない
できかた光が実際に集まるレンズを通して見える

物体の位置と像（Fは焦点、F′は焦点距離の2倍の位置）

物体の位置できる像大きさ
F′より遠い倒立の実像物体より小さい
F′の位置（焦点距離の2倍）倒立の実像物体と同じ
FとF′の間倒立の実像物体より大きい
Fの上（焦点上）実像も虚像もできない
Fより内側正立の虚像物体より大きい
  • 焦点の外側から物体を焦点に近づけていくと、実像のできる位置は遠ざかり、実像は大きくなる
  • レンズの一部をおおうと、像の大きさ・形・向き・位置は変わらないが暗くなる（集まる光の量が減るため）

身のまわりの凸レンズ

  • カメラ＝物体は焦点の外側。撮像素子に実像ができる
  • ルーペ（虫眼鏡）＝物体を焦点の内側に置き、拡大された虚像を見る
  • 虫眼鏡で遠くの景色を見ると（物体が焦点の外側）→ 小さい倒立の実像が見える
実像の高さ　a：b＝ℓ：x　（a＝光源と凸レンズの距離、b＝凸レンズと実像の距離、ℓ＝光源の高さ、x＝実像の高さ）

音の発生と伝わり方

  • 音源（発音体）＝音を出している物体。音は物体の振動によって発生する
  • 波＝振動が次々に伝わる現象。音は空気の濃い・うすいが次々に伝わる波
  • 音が伝わるとき、空気そのものは移動せず、振動だけが伝わる
  • 音を伝えるもの＝気体・液体・固体すべて。真空中では伝わらない
  • 耳の中の鼓膜が振動して音が聞こえる

音の速さ

  • 空気中 約340m/s／水中 約1500m/s（固体＞液体＞気体）
  • いなずまが見えてから雷鳴が聞こえるのは、音の速さが光の速さ（約30万km/s）よりはるかに遅いため
音の速さ〔m/s〕＝音源までの距離〔m〕音が伝わる時間〔s〕　　距離＝速さ×時間　　時間＝距離速さ
壁で反射した音（やまびこ）　音が伝わった距離＝壁までの距離×2

音の大きさと高さ

決めるもの大きく／高くする波形
音の大小振幅（振れ幅）振幅を大きく（強くはじく）山が高い
音の高低振動数〔Hz〕振動数を多く波の数が多い
  • 振動数＝1秒間に振動する回数。単位はヘルツ（Hz）
  • 波形のグラフ：縦軸＝振幅（音の大小）／横軸＝時間（波の数＝音の高低）
振動数〔Hz〕＝振動した回数〔回〕振動した時間〔s〕　＝11回の振動にかかる時間〔s〕

弦（モノコード）と音の高さ

変えるもの変わるのは高い音が出る条件
はじく強さ振幅（音の大小）―（高さは変わらない）
弦の長さ振動数（音の高低）短いほど高い
弦の太さ細いほど高い
弦の張り方強く張るほど高い

いろいろな音源（ひっかけ注意）

  • 試験管の口をふく：振動しているのは中の空気。空気の部分が短い＝水が多いほうが音が高い
  • ビーカー・試験管をたたく：振動しているのは容器と水。水が多いほうが音が低い（振動しにくいため）
  • 音さを鳴らして水に入れると水しぶきが上がる＝音さが振動している証拠
  • 同じ高さの音が出る音さAをたたくとBも鳴り出す＝空気の振動が伝わったため

力の3つのはたらき

  • ① 物体の形を変える（ゴム風船を押す）
  • ② 物体を支える（バーベルを持ち上げて静止）
  • ③ 物体の運動の状態を変える（バットでボールを打つ）

いろいろな力

力どんな力かふれ合う／離れていても
弾性力変形した物体がもとの形に戻ろうとする力ふれ合ってはたらく
摩擦力ふれ合う面で運動を妨げる向きにはたらく力
垂直抗力面に接した物体が面から垂直に受ける力（面の弾性力）
重力地球が中心に向かって物体を引く力離れていてもはたらく
磁力磁石の極と極の間・鉄を引きつける力
電気力＋と−は引き合い、同じ電気は反発する力

力の大きさとフックの法則

  • 力の単位はニュートン（記号 N）。1Nは地球上で約100gの物体にはたらく重力の大きさ（正確には0.98N）
  • フックの法則＝ばねののびは、ばねを引く力の大きさに比例する
  • ★比例するのは「ばねののび」。ばねの長さは比例しない（自然長のぶんずれる）
  • ★横にしたばねを両側から3Nで引いたとき、ばねにはたらく力は3N（6Nではない）
  • グラフは測定点の近くを通る直線を引く。折れ線にしてはいけない
重力〔N〕＝質量〔g〕÷100　　（例）250g → 2.5N ／ 1kg → 約10N

質量と重さ

質量重さ
意味物体そのものの量物体にはたらく重力の大きさ
単位g・kgN
はかる器具上皿てんびんばねばかり
場所で変わるか変わらない変わる
月面（重力は16）地球と同じ分銅とつり合う地球上の約16を示す

力の表し方と2力のつり合い

  • 力の3要素＝力のはたらく点（作用点）・力の向き・力の大きさ
  • 矢印の始点＝作用点／向き＝力の向き／長さ＝力の大きさ
  • 重力は物体の中心（作用点）から1本の矢印でかく
  • 作用線＝力の矢印に重ねて引いた直線。作用線上で作用点を動かしても力のはたらきは変わらない
2力がつり合う3条件　① 大きさが等しい　② 向きが反対　③ 一直線上にある（作用線が一致）
  • 机の上で静止：重力とつり合うのは垂直抗力
  • 押しても動かない：押す力とつり合うのは摩擦力
  • ばねにつり下げて静止：重力とつり合うのは弾性力
  • 2力の大きさがちがうときは、大きいほうの力の向きに動く

圧力

  • 圧力＝面を垂直に押す力のはたらきの大きさ。同じ面積あたりの力の大きさで表す
  • 単位はパスカル（記号 Pa）。1Pa＝1N/m²＝1m²の面を1Nの力で垂直に押すときの圧力
  • 1m²＝10000cm²（cm²で計算したら10000でわってm²にする）
圧力〔Pa〕＝面を垂直に押す力〔N〕力がはたらく面積〔m²〕

面積と圧力

  • 同じ力なら、面積が小さいほど圧力は大きい
  • 画びょう・包丁・スパイク＝面積を小さくして圧力を大きくする
  • スキー板・キャタピラ・ラクダの足＝面積を大きくして圧力を小さくする
  • 直方体を置く向きを変えると、力は同じでも面積が変わるので圧力は変わる（下にする面がいちばん小さいとき圧力が最大）
  • 同じ物体を2段に重ねると、面積は同じで力が2倍→圧力も2倍

大気圧（気圧）

  • 大気圧＝空気の重さによって生じる圧力。あらゆる向き（上下左右すべて）にはたらく
  • 海面付近では約1013hPa（＝約1気圧）。1hPa＝100Pa
  • 標高が高いほど上にある空気が少ないので、大気圧は小さくなる（山でお菓子の袋がふくらむ）
  • 容器の空気を抜くとつぶれるのは、外からの大気圧のほうが大きくなるため

水圧

  • 水圧＝水の重さによって生じる圧力。あらゆる向きにはたらく
  • 深いほど上にある水が多いので、水圧は大きくなる
  • 深海用の潜水艇が丈夫につくられているのは、深いところの水圧が非常に大きいため

音の速さ

速さ〔m/s〕＝距離〔m〕時間〔s〕　　距離＝速さ×時間　　時間＝距離速さ
  • （例）510m はなれた所で1.5秒後に音が聞こえた → 510÷1.5＝340m/s
  • 壁で反射した音は往復するので、距離＝壁までの距離×2
  • （例）壁から170mの位置で音を鳴らすと、340×？＝170×2 → 1秒後に反射音が聞こえる

振動数

振動数〔Hz〕＝振動した回数〔回〕振動した時間〔s〕　＝11回の振動にかかる時間〔s〕
  • （例）10秒間に3000回 → 3000÷10＝300Hz
  • （例）0.002秒で1回 → 1÷0.002＝500Hz／1400秒で1回 → 400Hz
  • 波形は「1回の振動が何目盛りか」を数え、1目盛りの時間をかけて1回の振動の時間を出す

ばねののび（フックの法則）

のび＝1Nあたりのび×力〔N〕　　ばねの長さ＝自然長＋のび　　力〔N〕＝質量〔g〕÷100
  • （例）0.5Nで2cmのびるばね → 1Nで4cm。60gのおもり（0.6N）なら 4×0.6＝2.4cm
  • ★「ばねの長さ」を聞かれたら自然長をたし忘れない

重さと質量

重力〔N〕＝質量〔g〕÷100　　月面での重さ＝地球上の重さ×16　（質量は変わらない）

圧力

圧力〔Pa〕＝力〔N〕面積〔m²〕　　面積〔m²〕＝面積〔cm²〕÷10000
  • （例）質量600gの直方体を10cm×20cmの面で置く → 力6N、面積0.02m² → 6÷0.02＝300Pa

凸レンズ

a：b＝ℓ：x　（a＝光源と凸レンズの距離、b＝凸レンズと実像の距離、ℓ＝光源の高さ、x＝実像の高さ）
  • 物体と同じ大きさの実像ができるのは、物体が焦点距離の2倍の位置にあるとき（そのときスクリーンも焦点距離の2倍の位置）
  • （例）物体を24cmの位置に置いて同じ大きさの実像 → 焦点距離は12cm
